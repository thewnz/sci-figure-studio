# 数据图手册

## 选图

| 数据关系 | 首选 | 避免 |
| --- | --- | --- |
| 随步数/时间变化 | 折线 + 误差带/误差线 | 3D 折线、双 Y 轴滥用 |
| 多方法 × 多基准 | 分组柱状 / 点图 | 饼图、堆叠柱当分组比较 |
| 单指标排名 | 水平柱状（leaderboard） | 倾斜标签 |
| 两连续变量 | 散点 + 趋势线（有依据时） | 过度拟合线 |
| 矩阵/混淆矩阵 | 热图 + 数值标注 | 彩虹色阶 |
| 分布 | 箱线/小提琴/雨云 + 原始点 | 只画均值柱 |
| 比例构成 | 堆叠条 / 点图 | 多类饼图 |
| 消融 | 分组柱 / 斜率图 | 只列表格不画图 |

## 统计与标注

- 明确误差线：s.d.、s.e.m.、95% CI、IQR；图注写 `n`。
- 显著性：只有做了检验才标；写清检验方法与校正。
- 不要用误差线暗示没有的重复测量。
- 对数轴必须标清；零值不能放 log 轴。
- 坐标轴从 0 开始不是铁律，但截断轴要明确标注。
- 百分比与百分点不要混用。

## 样式

- 期刊默认：白底、无网格、左/下轴、刻度朝外、细线。
- Nature：轴线与刻度必须有；轴标签写 `Data (unit)`；无背景网格。
- 字号：Nature 5–7 pt；Science/Cell 6–8 pt；IEEE/Springer/PLOS 8–12 pt；ML 8–10 pt。
- 线宽：Nature 0.25–1 pt；其他通常 0.5–1.5 pt。
- 标记：≥3 pt；不同方法用不同标记 + 线型，不只换颜色。
- 图例：优先直接标注；图例不遮挡数据；多列时控制行数。

## 色板

默认 Okabe–Ito：

`#0072B2` 蓝、`#E69F00` 橙、`#009E73` 绿、`#CC79A7` 粉、`#56B4E9` 天蓝、`#D55E00` 朱红、`#F0E442` 黄、`#000000` 黑。

- “我们的方法”用强调色（橙/朱红），基线用灰蓝/灰。
- 连续色阶优先 `viridis`、`cividis`、`RdBu_r`（发散）；避免 `jet`。
- 色盲检查：protan/deutan/tritan 三类模拟下仍能区分；同时保留线型/标记/直接标签。
- 灰度检查：转灰度后亮度差不足时，增加纹理或直接标签。

## 导出

- PDF：矢量，`pdf.fonttype=42`，字体嵌入；最终尺寸就是画布尺寸。
- SVG：`svg.fonttype=none`，文字保留为 `<text>`。
- PNG：600 dpi 用于审稿/预览；不要用 PNG 提交线图。
- TIFF：按期刊要求 300/600 dpi，RGB，压平透明。
- 不要 `bbox_inches='tight'` 改变物理尺寸；用 constrained layout 保证标签在画布内。

## 常见错误

- 图例遮住数据 / 图例重复颜色。
- 刻度标签过密；用 `MaxNLocator`。
- 字号在图里 10 pt、缩到单栏后只剩 5 pt。
- 用颜色区分 12 条线；改为分面或直接标注。
- 热图没有色条单位/范围。
- 柱状图没有误差线却声称差异显著。
- 图内标题与图注重复。
