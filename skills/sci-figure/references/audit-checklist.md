# 投稿前审计清单

自动审计覆盖“文件层面能测的东西”；本清单覆盖“机器测不出的科学/编辑问题”。

## A. 技术合规（机器可测）

- [ ] 画布宽度 = 目标栏宽（89/183、85/174、90/190、3.5/7.16 in 等），误差 ≤1 mm。
- [ ] 高度 ≤ 期刊最大高度。
- [ ] 位图有效 DPI ≥ 期刊下限；线条/文字是矢量。
- [ ] 图内最小字号 ≥ 期刊下限；最大字号不超过上限。
- [ ] 字体在允许列表；PDF 字体已嵌入；没有 Type 3。
- [ ] 文字未被转曲（PDF 仍可选中/编辑文本）。
- [ ] RGB（或期刊要求 CMYK）；无多余透明度。
- [ ] 文件格式在期刊接受列表；体积不超限。
- [ ] 色盲模拟下颜色可区分；灰度下亮度差足够。
- [ ] 内容不贴边、不被裁切；页面数正确。

## B. 科学内容（人工）

- [ ] 图能独立回答 `purpose`。
- [ ] 数据点、均值、误差线、样本量与原始数据一致。
- [ ] 误差线定义写清（s.d./s.e.m./CI/IQR），`n` 写清。
- [ ] 显著性标注有检验依据；多重比较已校正。
- [ ] 坐标轴单位、量纲、对数轴标注正确。
- [ ] 缺失值/排除标准在图注说明。
- [ ] 图像完整性：没有不当拼接、重复使用、过度对比度调整。
- [ ] 显微图有比例尺；比例尺未被压平进位图。
- [ ] 流程图模块/箭头与正文方法一致；没有多余因果。
- [ ] 颜色语义全文一致（同一方法同色）。

## C. 编辑与可读性（人工）

- [ ] 图注自足：不看正文也能理解图。
- [ ] 面板标签连续、大小写/字重符合期刊。
- [ ] 术语、缩写、大小写与正文一致。
- [ ] 图例不遮挡数据；直接标注优先。
- [ ] 文字不压在复杂图像/深色背景上。
- [ ] 图中没有标题、致谢、作者信息。
- [ ] 多面板对齐、留白、视觉层级稳定。
- [ ] 灰度打印/手机屏幕仍可读。

## D. 许可与来源（人工）

- [ ] 第三方图标/插图有许可记录；CC BY 已署名。
- [ ] 参考图只用于构图，不复制受版权保护的表达。
- [ ] 字体许可允许嵌入/再分发。
- [ ] AI 生成元素已按期刊政策声明（如适用）。
- [ ] 数据/代码可用性声明与图一致。

## 修复优先级

1. 画布尺寸/栏宽错误（会导致整图缩放）。
2. 字体未嵌入/转曲（会导致缺字或被退回）。
3. 分辨率不足（位图线图）。
4. 字号过小/过大。
5. 色彩模式/透明度。
6. 色盲/灰度可访问性。
7. 贴边/裁切/留白。
8. 图注、术语、面板标签。

